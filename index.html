Questions developers ask first.

The short answers, without a sales call.

Does PlainTake record audio?

Optionally. --speech on reads each caption aloud with a voice model that runs on your own machine — no network, no account, no API key — and --speech file speaks WAV recordings you supply. Hard captions remain the default either way, because they stay visible in browsers, social feeds, and documentation embeds. Narration is a Pro feature.

Does recording contact a cloud service?

No. Recording and rendering have no runtime network dependency beyond the app you explicitly point Chromium at. Pro activation is one separate, user-initiated licence check; later runs use the cached result.

Can it record an authenticated app?

Yes. A scenario can declare a pre-flight handoff so you sign in through the real browser before screencast and trace capture begin.

Can an AI coding agent run it?

Yes. PlainTake ships a local stdio MCP server with validate, run, render, and verify tools, plus matching CLI commands.

Can I re-render without opening Chromium?

Yes. The frozen render plan and raw capture are part of the bundle. Re-rendering verifies the source hash before FFmpeg starts.
